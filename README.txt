# RE:FORM — iPhone用Webアプリ

## 含まれるファイル
- `index.html`: アプリ本体
- `manifest.json`: ホーム画面追加用設定
- `sw.js`: オフライン表示用キャッシュ
- `icon-192.png`, `icon-512.png`: アプリアイコン

## 重要：iPhoneに追加するにはHTTPSで公開が必要
このフォルダをそのまま「ファイル」アプリから開いただけでは、PWAとしてのインストールやサービスワーカーは動きません。Safariで開けるHTTPSのURLに公開してから追加してください。

### GitHub Pagesを使う場合（無料の一例）
1. GitHubでログインし、新しい公開リポジトリを作成します（例 `reform-app`）。
2. このZIPを解凍し、中の5ファイルをリポジトリのルートにアップロードします。
3. リポジトリの Settings → Pages → Build and deployment で `Deploy from a branch` を選び、`main` / `/(root)` を指定して保存します。
4. 公開されたURL（通常 `https://ユーザー名.github.io/reform-app/`）をSafariで開きます。
5. Safariの共有ボタン →「ホーム画面に追加」→「追加」。
6. 追加されたRE:FORMアイコンから起動します。

## データ保存と制約
- 日々の記録はブラウザの `localStorage` に保存され、サーバーには送信されません。
- 同じiPhone・同じ公開URL・同じブラウザ環境で使ってください。Safariで開いた状態とホーム画面アプリの保存領域は、iOSのバージョンや起動方法によって同じ扱いにならない場合があります。最初にテスト記録を作り、Safariとホーム画面の両方で見えるか確認してください。
- Webサイトデータを消す、ブラウザを変える、端末が故障する、ストレージが消去されるなどで記録が失われる可能性があります。設定タブからJSONバックアップを定期的に書き出してください。
- JSONバックアップは端末内の「ファイル」などに保存し、必要なら設定タブから復元できます。
- データ同期や自動クラウドバックアップはありません。
- このアプリは2026-10-18〜2026-12-31を記録対象期間として設定しています。コードを変更すれば期間を延長できます。

## 使用上の注意
栄養目標は初期値の目安です。体重・腹囲・トレーニングの数週間の傾向を見ながら調整してください。
